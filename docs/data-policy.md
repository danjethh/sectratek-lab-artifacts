# Data policy

## Where the research comes from

The Lab Technical Reports are based on real devices from real cases, submitted to the Lab for the purpose of research. Material from these devices is confidential. It is never published, in this repository or anywhere else.

## What this repository holds instead

Every dataset here is **synthetic or a fixture**: generated by code in the package, or written by hand, to reproduce the structures, formats and behaviors the Lab observed on the real devices. They are built this way so that:

- no case data is exposed;
- privacy of the people behind the devices is protected;
- anyone can run the methods and check the results without access to the real material.

Values in the fixtures are invented. Where a report's finding depends on a property of the real corpus (for example a rate or a range), the package reproduces the mechanism on synthetic data and the report prints the measured aggregate.

## What is published

- Code that reads, measures, simulates or checks.
- Synthetic and fixture data, marked as such.
- Aggregate results the reports already print.

## What is never published

- Data from any real phone, extraction, bug report, sysdiagnose or backup.
- Names, numbers, accounts, message text, locations or identifiers of any real person or organization.
- Case or engagement information of any kind.
- The reference implementations the Lab keeps private. Where a package re-implements a method, its README says so.

## What a package can and cannot reproduce

A package's README separates what you can recompute from the synthetic data and what you can only read in the report, because it depends on the confidential corpus.

## If you find a problem

If you believe a file contains real device data or a real person's information, do not copy or share it further. Follow [SECURITY.md](../SECURITY.md).
