# How to cite

## A report

Cite the Lab Technical Report for any result. Reports on Zenodo carry a DOI; use the concept DOI to point at the newest version, or a version DOI to pin one. DOIs are in the tables of the [README](../README.md) and in [`catalog.json`](../catalog.json).

Format:

> Addai, D. K. N. et al. (2026). *Title*. SectraTEK Lab Technical Report LAB-TR-NNNN. https://doi.org/10.5281/zenodo.NNNNNNNN

Reports without a DOI yet: cite the report number, title and year, and the folder in this repository.

## A package

Cite the package when you reuse its code or data. Use the repository and the folder:

> SectraTEK Lab (2026). *SectraTEK Lab research artifacts*, `reports/lab-tr-NNNN`. https://github.com/danjethh/sectratek-lab-artifacts

## The repository

GitHub's **Cite this repository** button reads [`CITATION.cff`](../CITATION.cff). BibTeX:

```bibtex
@software{sectratek_lab_artifacts_2026,
  author  = {Addai, Daniel Kwaku Ntiamoah},
  title   = {SectraTEK Lab research artifacts},
  year    = {2026},
  url     = {https://github.com/danjethh/sectratek-lab-artifacts},
  license = {MIT}
}
```
